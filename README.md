# COS202

COS202 coding assignments: Mathematical Calculator (MC) and Personal Pocket CGPA Calculator (PPC).

Name: Adebayo Emmanuel

## Files

- calculator.py - simple calculator with + - * / \ ^ % C (clear) and OFF
- cgpa.py - pocket CGPA calculator that also takes a previous CGPA and units
- mc.py and ppc.py - earlier versions of the same two programs
- screenshots - test runs and outputs
- COS202_Project_Report.docx - project report

## How to run

Python 3 is needed.

    py calculator.py
    py cgpa.py

## Calculator

Type an operator and press Enter, then type a number and press Enter. Type C to clear and OFF to turn it off.

## CGPA calculator

Enter your previous CGPA and units (0 if none), then the units and score for each course. Scores of 70 and above get an A, 60 to 69 a B, 50 to 59 a C, 45 to 49 a D and below 45 an F. The program prints the GPA, the CGPA and the class of degree.
